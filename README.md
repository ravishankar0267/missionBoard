# MissionBoard - EdTech Platform

A modern education and learning platform built with cutting-edge cloud technologies.

## Tech Stack

### Backend
- **Appwrite Functions**: Serverless backend using .NET 8
- **Database**: Supabase PostgreSQL
- **Storage**: Appwrite Storage (PDFs, Videos, Media)
- **Authentication**: Appwrite Auth with Google Social Login

### Frontend
- **Framework**: React
- **Hosting**: Appwrite Sites
- **Styling**: Tailwind CSS
- **State Management**: React Query + Context API

## Project Structure

```
missionBoard/
├── backend/              # .NET 8 Appwrite Functions
├── frontend/             # React Application
├── infrastructure/       # Appwrite & Supabase Config
├── docs/                 # Documentation
└── README.md
```

## Getting Started

See individual README files in `backend/` and `frontend/` directories for setup instructions.

## Features

- User authentication with Google Social Login
- Course management and enrollment
- Video streaming and PDF resources
- Progress tracking
- User dashboard
- Responsive design
